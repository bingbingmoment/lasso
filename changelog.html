更新日志

Lassomark 每个版本改了什么，都记在这里。已安装的用户在菜单栏「检查更新」即可升级。

2.1

2026年10月1日

新增新手引导

  • 新增新手引导，跟着做一遍就会用；菜单里的「使用指南」随时可以再打开。

2.0

2026年9月27日

Agent 模式：人和 AI 都能用

  • 新增 Agent 模式（⇧⌘C）：跨应用识别屏幕上的界面组件，鼠标经过即高亮，点一下就选中。
  • 给每个组件写下修改要求，自动编号 ①②③；写好的标注可以再次编辑、拖动或删除。
  • 再按一次 ⇧⌘C（或点「复制 Prompt」），标注就变成结构化的 Prompt 进了剪贴板，直接粘贴给 AI；按 ⇧⌘V 粘贴还能附带截图。
  • 菜单瘦身：去掉「圈选标注」和「识别灵敏度」，两个模式的按钮不再重复。
  • 改用 Apple 开发者证书签名并通过公证，安装时不再提示「无法验证开发者」。因为签名变了，更新后请到「系统设置 › 隐私与安全性」的「屏幕录制」和「辅助功能」里，选中旧的 Lassomark 点「−」删掉，再点「+」重新添加（只拨开关不管用）。

1.2

2026年8月1日

修两个小毛病

  • 开启「2× 光标」时，系统光标和放大光标不会再叠成两个。
  • 在副屏上做的标注，用整屏快照（⇧⌘S）存下来的终于是副屏画面，不再错截成主屏。

1.1

2026年7月19日

改名 Lassomark

  • Lasso 正式更名为 Lassomark，功能与上一版一致。
  • 自动更新改为直连 lassomark.com，检查更新更稳定。1.0 及更早的版本需要手动下载一次新版。

1.0

2026年7月18日

选区复制、选区录制

  • 新增选区复制：标注完框选一块区域，松手就复制到剪贴板。
  • 新增选区录制：框选区域后立即开录，再按一次快捷键结束。
  • 快捷键调整：标注模式开关改为 ⇧⌘E，整屏录制 ⇧⌘1，选区录制 ⇧⌘2。
  • 文字卡片和整体界面细节打磨。
